## 转换工具优先级

1. **docx/docx** → `markitdown` (pandoc 后端)
2. **wps** → `LibreOffice` 转 docx 再 markitdown
3. **xlsx/xls** → Python pandas 输出 markdown table
4. **pdf** → `pdfplumber` 或 `markitdown`
5. **已有 .md** → 直接复制
